# Каталог товаров
 
Учебный проект по дисциплине «Оптимизация веб-приложений».
Интернет-каталог на Node.js без сторонних библиотек.
 
## Как запустить
 
1. Установите Node.js версии 20 или новее.
2. Создайте каталог товаров командой `node generate-products.js`
3. Создайте папку `public/fonts` и скопируйте в неё шрифт `comic.ttf`
   из папки `C:\Windows\Fonts`. Без шрифта сайт тоже работает,
   только другим шрифтом.
4. Запустите сервер командой `node server.js`
5. Откройте в браузере http://localhost:3000
 
## Что оптимизировано
 
| Работа | Что сделано |
|---|---|
| 4 | Фото уменьшены, размеры заданы заранее, отложенная загрузка |
| 5 | Лишние стили убраны, главные стили внутри страницы |
| 6 | Шрифт не прячет текст при загрузке, предзагрузка шрифта |
| 7 | Сборка с минификацией в папку dist |
| 8 | Карточки вставляются разом, чтение и запись размеров разделены |
| 9 | Поиск с паузой, прокрутка с пропуском, один обработчик кнопок |
| 10 | Сжатие ответов gzip |
| 11 | Выдача по страницам, подгрузка, поиск на сервере |
| 12 | Кеширование: ETag, ответ 304, срок хранения картинок |
| 13 | Каталог хранится в памяти сервера |
